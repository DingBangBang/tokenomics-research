# 高资金费率是否预示市场回调？——来自加密衍生品市场的实证

**研究笔记 No.04 · Tokenomics · 区块链经济学及应用趋势研究**

- **作者**：Bonnie Bennett（Senior Data Analyst / Data Scientist）
- **发布日期**：2026-10
- **方法**：Hyperliquid 公开 info API（小时级资金费率 + 日线价格）+ 十分位/前瞻收益分析
- **代码/数据**：[`tools/build_charts.py`](../tools/build_charts.py)、[`data/`](../data)
- **一句话结论**：在**日频**尺度上，资金费率是一个**很弱**的反向信号——`CORR(funding, 未来 7 日收益) = −0.064`，最高资金费率十分位的未来 7 日收益（+0.12%）**略低于**最低十分位（+0.22%），但差异不足以构成可靠的"见顶"交易信号。资金费率更适合做**拥挤度度量**，而非择时开关。

## 摘要

永续合约的**资金费率（funding rate）**是多空双方的定期支付：当费率**为正**，多头付费给空头，代表**多头拥挤**；费率为负则相反。市场流行一个直觉——**"资金费率飙升 = 杠杆过热 = 即将回调"**。本文用 **Hyperliquid BTC 永续的 359 天日频样本（2025-10 → 2026-10）**检验这一直觉：

- **发现 1（分布）**：日度资金费率**均值 +0.0158%**，区间 **[−0.0416%, +0.05%]**，**359 天中有 58 天为负**（占 16%）——说明市场多数时间处于"多头付费"的偏多状态，但也常有空头拥挤的时段。
- **发现 2（弱反向）**：`CORR(资金费率, 未来 7 日收益) = −0.064`——**方向为负但极弱**。资金费率越高，未来一周收益**略微**越低，符合"拥挤→回调"的方向，但解释力微乎其微。
- **发现 3（十分位）**：按资金费率分 10 桶，**最高分位 D10 的未来 7 日平均收益 +0.12%**，**最低分位 D1 为 +0.22%**——两者差异 **约 0.1 个百分点**，统计与经济意义都很弱。
- **发现 4（结论）**：在**日频**尺度，资金费率**不是**可靠的择时信号；它更适合作为**市场情绪/拥挤度的面板指标**，需与价格动量、持仓量、波动率等**联合使用**。

**政策含义**：交易所/机构在做风险监控时，应把资金费率当作**连续的拥挤度指标**（配合阈值告警），而**不要**把它当作独立的"看跌触发器"。

## 1. 研究问题

- **RQ1**：资金费率的分布特征（均值、极值、负值占比）如何？
- **RQ2**：资金费率与**未来收益**（1 日/7 日）是否存在（负）相关？
- **RQ3**：极端的资金费率分位是否对应显著不同的未来收益？

## 2. 背景：资金费率的经济学

永续合约没有到期日，靠**资金费率**锚定现货价格：

```
funding > 0 : 多头 → 空头（多头拥挤/溢价）
funding < 0 : 空头 → 多头（空头拥挤/折价）
```

逻辑上，**高正资金费率 = 多头杠杆拥挤 = 潜在的多杀多风险**，因此常被视作"见顶"信号。但这一直觉面临两个挑战：

1. **趋势中的高费率可持续**：强趋势里多头愿意持续付费，费率高位可以维持很久；
2. **存在"费率套利"资金**：正费率会吸引套利者做空永续/做多现货，**平滑**了费率信号。

## 3. 文献综述

- 关于加密衍生品的实证多聚焦**基差与持仓量**，对**资金费率的择时价值**的系统检验相对稀缺；
- 本文贡献：用**免 key 的公开数据**给出资金费率与前瞻收益关系的**可复算证据**，并诚实报告其**弱有效性**。

## 4. 数据与方法

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 小时级资金费率 | Hyperliquid `fundingHistory`（POST `/info`） | 聚合为日度（当日小时费率求和，%） |
| 日线价格 | Hyperliquid `candleSnapshot` | 用收盘价计算前瞻收益 |

- 样本：**359 个交易日**（2025-10-09 → 2026-10-02）。
- 指标：`funding_d`（日度资金费率 %）、`fwd7_d`（未来 7 日收益 %）。
- 方法：相关系数 + **十分位分组**（D1 = 费率最低，D10 = 最高）。
- 局限：单一资产（BTC）、单一样本窗口；未控制趋势/波动率。

## 6. 讨论：为什么"见顶信号"这么弱？

1. **趋势的力量**：牛市中高费率可长期维持，费率本身不包含"何时反转"的信息；
2. **套利平滑**：正费率吸引基差套利，抑制了费率的极端化；
3. **日频噪音**：7 日窗口内价格由多重因素驱动，单靠费率解释力有限；
4. **条件依赖**：费率信号可能在**结合高波动/滞涨**时才有效（需交互项建模）。

## 7. 结论与建议

1. **资金费率是"拥挤度"而非"择时器"**：它告诉我们多头有多拥挤，但**不告诉我们何时**回调。
2. **建议 A｜作为连续风控指标**：把资金费率纳入实时监控，设**分位阈值告警**（如 >95 分位），而非二元买卖信号。
3. **建议 B｜联合建模**：与**波动率、持仓量、价格动量**组合，构造"杠杆拥挤度"复合因子。
4. **建议 C｜交易所产品含义**：在高费率期收紧高风险账户杠杆、提高保证金要求，属**审慎监管**的合理动作。

## 8. 局限与后续研究

1. 单一资产/窗口，需跨资产（ETH、SOL）与更长时间验证；
2. 未做**多因子回归**与**事件研究**（费率极端后的条件收益）；
3. 后续可检验**费率 + 未平仓量**的交互效应，或引入**基差**作为补充。
